# ONE ERA — Phase 2 Website Skeleton

Static front-end skeleton based on the ONE ERA Brand Foundation v1.0.

Included:
- Home
- Shop
- Collections
- Product page
- Learn
- Practice
- Discover
- Journal
- About / The Society
- Cart
- Checkout

Brand system:
- Cormorant Garamond + DM Sans
- Obsidian #11100F
- Warm Bone #E8DFD2
- Deep Forest #173C35
- Mystic Rose #C88F9D
- Celestial Blue #536F86
- Burnished Flame #C45B3C
- Mineral Green #718A78
- Solar Ochre #C4A052

Cart is a browser-local mock using localStorage.
Checkout is a visual placeholder only; no payment or order backend is connected.
Replace placeholder visual blocks with approved ONE ERA photography / generated imagery in the next phase.
